# Docker secrets (override `docker-compose.secrets.yml`)

Files generated by `../gen-secrets.sh` (never versioned — cf. `.gitignore`):

- `graylog_password_secret` — Graylog encryption secret (≥ 64 chars)
- `graylog_root_password_sha2` — SHA-256 of the admin password
- `mobile_secret` — HMAC for console sessions
- `oms_teams_webhook` — Teams webhook URL (optional; empty = no notification)

Mounted at `/run/secrets/<name>` in the containers (invisible in `docker inspect`).
See `../docker-compose.secrets.yml` for usage.
