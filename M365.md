# Microsoft 365 → Graylog — integration plan (next step)

Objective: suspicious Entra ID sign-ins, risky sign-ins, Exchange/
SharePoint/Teams auditing, all normalized in Graylog (stream + dashboard + alerts).

## Chosen architecture (Graylog OSS, no paid plugin)

```
Entra ID / M365 ──Graph API / O365 Management Activity API──┐
                                                            ▼
              Python fetcher (cron 5 min, on the SIEM VM, persistent state)
                                                            ▼
              GELF HTTP input 127.0.0.1:12201 ──► stream "OMNI - M365"
              (pipeline: user/src_ip/action normalization + GeoIP + alerts)
```

## What we will collect

| API source | Content | Value |
|---|---|---|
| Graph `auditLogs/signIns` | sign-ins (IP, country, MFA, device, failure/success) | impossible travel, unusual country, spray |
| Graph `identityProtection/riskyUsers` + `riskDetections` | Microsoft scoring | directly reused as P3 alerts |
| Graph `auditLogs/directoryAudits` | Entra changes (roles, apps, MFA reset) | sabotage / cloud persistence |
| O365 Mgmt Activity `Audit.Exchange` / `Audit.SharePoint` | mailbox rules, shares, DLP | exfiltration, malicious forwarding rules |

## Prerequisites to do on the tenant side (you, ~15 min)

1. **Entra ID > App registrations > New**: `OMNI-SIEM-Collector`.
2. **API permissions** (*Application* type, then "Grant admin consent"):
   - Microsoft Graph: `AuditLog.Read.All`, `IdentityRiskyUser.Read.All`,
     `IdentityRiskEvent.Read.All`, `Directory.Read.All`
   - Office 365 Management APIs: `ActivityFeed.Read`
3. **Certificates & secrets**: create a client secret (24 months max).
4. Provide me (to put in `00-vars.env`):
   ```
   M365_TENANT_ID='...'
   M365_CLIENT_ID='...'
   M365_CLIENT_SECRET='...'
   ```
5. Verify that the SIEM VM has HTTPS egress to `login.microsoftonline.com`,
   `graph.microsoft.com`, `manage.office.com` (FortiGate policy VLAN 220 -> WAN).

## What I will do next (scripts 16-17, already scoped)

- `16-m365-input.sh`: GELF HTTP input (127.0.0.1:12201), index set
  `omni-m365` (180 days - cloud traceability), stream + pipeline (normalization
  to the OMNI schema: `user`, `src_ip`, `event_action`, `alert_tag`).
- `17-m365-fetcher.sh`: deploys `/usr/local/sbin/omni-m365-fetch.py`
  (persistent cursors in /var/lib/omni-m365, dedup, 429 backoff)
  + systemd timer 5 min.
- Alerts: `OMNI - M365 risky sign-in (Identity Protection)`,
  `OMNI - M365 unusual country sign-in`, `OMNI - M365 mail forwarding
  rule created`, `OMNI - M365 privileged role assigned`.
- Dashboard `OMNI - Microsoft 365`: sign-in map, MFA failures,
  risky users, admin activity.
