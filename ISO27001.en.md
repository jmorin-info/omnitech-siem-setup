## Gaps to address (by priority)

1. ❌ **Off-site evidence (5.33, 8.13)** — backups remain on the
   host (`/home/siem-backup`). An attacker who takes over the VM wipes everything.
   → Action: daily rsync to the NAS (or S3 repo) **in push mode with a
   dedicated write-only account**; ideally immutability (NAS snapshot).
2. ❌ **Documented restore test (8.13)** — the restore has never
   been rehearsed. → Action: quarterly exercise: restore mongodump + 1
   snapshot on a throwaway VM, record duration/result (audit evidence).
3. 🟡 **Traceability of actions on the SIEM (8.15)** — admin actions in
   Graylog are only traced by the nginx access.log (the application audit log
   is an Enterprise feature). → Action: retain/export
   `/var/log/nginx/access.log` (90 d) + `auditd` on the VM; ban the
   shared admin account (create named accounts).
4. 🟡 **Named accounts + MFA (5.16, 5.17)** — `admin` is shared and without
   MFA. → Action: one named account per admin; at the front, pre-authentication
   possible via nginx (mTLS PKI certificates) if the requirement is strong.
5. 🟡 **Source coverage (8.15)** — missing: DHCP (filebeat on the
   DC DHCP logs), DNS Server (analytical audit), Veeam backups
   (events), ESXi/vCenter (syslog 1514 already ready on the Graylog side).
6. 🟡 **Response procedure (5.26)** — alerts go out over mail+Teams but
   without a written procedure (who qualifies, within what time, escalation).
   → Action: 1-page runbook per alert family (P3 = 1 business hour, etc.).
7. 🟡 **Periodic review (5.36)** — the weekly report exists; formalize a
   monthly review (false positives, thresholds, new detections) with a record.
8. ❌ **M365 secret and certificates: lifecycle management (5.37)** — Entra
   client secret (24 months) and PKI cert (2028-06-10) will expire silently.
   → Action: deadlines on the calendar + deadman alert (the silence of the
   M365 collector will trigger "0 message" — add a dedicated alert).
9. 🟡 **VM hardening (8.9)** — sound Debian base (localhost services,
   nftables); complete: automatic security updates (unattended-upgrades),
   auditd, SSH banners, SSH key rather than root password.

## Retention rationale (to be recorded in the policy)
- Windows Security / FortiGate: 90 d online (routine investigation)
- Sysmon / other channels: 60 d (volume)
- M365: 180 d (cloud traceability, no other internal copy)
- Long term: daily snapshots, 14 d local + NAS export to be set up
  (recommended target: 1 year for authentication evidence).
