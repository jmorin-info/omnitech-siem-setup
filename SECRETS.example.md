## Sensitive files and expected permissions
- `00-vars.env` → `chmod 600 root:root`
- `/root/.graylog_password_secret` → `600`
- `/etc/nginx/ssl/graylog.key`, `/etc/graylog/server/certs/graylog-pkcs8.key` → `600` / `640 root:graylog`
- `/etc/mongod.keyfile` → `400 mongodb:mongodb`
- `/root/.smb-siem.cred` → `600`

## Rotation (after stabilisation)
Per-secret procedure: admin password (SHA-256 hash → `server.conf`), Mongo
(`changeUserPassword`), re-create API tokens in the UI, automated TLS renewal
(`omni-cert-renew`). Log every rotation (A.5.37 / REG_016).
